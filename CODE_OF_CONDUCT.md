# Code of conduct

Everyone participating in this project, in issues, pull requests and
discussions, agrees to:

- Be respectful. Disagree with ideas, not people.
- Assume good faith and ask before concluding.
- Keep other people's personal data out of the repository and out of
  issues, including data copied from a job application.
- Accept maintainer decisions on scope; forks are welcome.

Harassment, discrimination, doxxing or sharing someone's application data
is grounds for removal. Report problems through the private security
advisory link in `SECURITY.md` or by email to the maintainer listed on the
GitHub profile.
